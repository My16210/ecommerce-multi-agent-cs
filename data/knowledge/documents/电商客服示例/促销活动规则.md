# 促销活动规则

## 一、常见活动类型

| 活动类型 | 玩法 | 能否与其他优惠叠加 |
| --- | --- | --- |
| 跨店满减 | 满 300 减 40，跨店铺合并计算 | 可与店铺券叠加 |
| 店铺满减 | 满 200 减 30 | 可与平台券叠加 |
| 优惠券 | 无门槛或有门槛抵扣 | 同类型券不叠加 |
| 秒杀 | 限时限量低价 | 不叠加任何优惠 |
| 团购 | 凑够人数享低价 | 不叠加任何优惠 |
| 直播间专享价 | 直播间内下单享低价 | 不叠加任何优惠 |

叠加顺序固定为：**秒杀/团购价 → 店铺满减 → 跨店满减 → 优惠券 → 积分抵扣**。
顺序由系统执行，消费者不需要也不可以手动调整。

## 二、跨店满减的计算

跨店满减按**商品实付金额**合并计算，不是按标价：

- 满减门槛看的是参与活动的商品合计金额，不含不参与活动的商品；
- 满减优惠按各商品金额**比例分摊**到每件商品上；
- 部分退货时，按分摊后的金额退款，因此退款额会少于商品标价。

举例：满 300 减 40，订单里 A 商品 200 元、B 商品 100 元。
A 分摊 26.67 元、B 分摊 13.33 元。只退 B 时退回 100 - 13.33 = 86.67 元。

## 三、优惠券

- **有门槛券**：需订单金额达到门槛才能使用，门槛按券适用范围内的商品金额计算；
- **店铺券**：只在指定店铺使用，一单只能用一张；
- **平台券**：全平台通用，一单只能用一张；
- 券的有效期以券面标注为准，过期不补发；
- 券不可转赠、不可提现、不可兑换现金。

**用券下单后取消订单**：券在有效期内会退回账户；
如果取消时券已过期，则不补发。因此不建议用快过期的券下大额订单。

## 四、秒杀与限量购

- 秒杀商品库存有限，售完即止，**加入购物车不代表锁定库存**；
- 秒杀订单不支持使用任何优惠券和满减；
- 秒杀商品同样适用七天无理由退货，但运费由消费者承担；
- 同一账号在同一场次内限购件数由商品页标注，超拍的订单可能被取消；
- 使用脚本、多账号抢购的账号会被限制参与后续活动。

## 五、预售与定金

预售商品分"定金 + 尾款"两段支付：

- 定金在预售期内支付，按定金金额的 2 倍抵扣尾款；
- 尾款需在指定时间段内付清，**逾期未付尾款定金不退**；
- 定金不退是行业惯例，但若因商家未按时发货导致无法完成交易，定金全额退还；
- 预售商品在尾款支付后才计算发货时效。

## 六、价格保护与活动的关系

参与秒杀、团购、直播间专享价、跨店满减的商品，**不在价保范围内**。
其他情况下的降价，可在 15 日内申请价保，详见《售后政策》。

参与活动下单后又申请价保的，价保金额以活动后的实际支付金额为基准计算，
不会重复享受两次优惠。

## 七、常见问题

**问：为什么结算页的价格和详情页的"到手价"不一样？**
详情页的"到手价"通常是"标价 - 商品券"，不含需要凑单的跨店满减。
结算页的金额才是最终应付金额。凑不满门槛时，以结算页为准。

**问：满减的"满"是含运费吗？**
不含。运费不参与满减门槛的计算，也不参与满减分摊。

**问：退货后满减优惠会返还吗？**
不会以券的形式返还，但会按分摊比例体现在退款金额里。
如果整单全退，相当于优惠全额返还。

**问：可以指定把满减优惠分摊到某一件商品上吗？**
不可以。分摊由系统按比例执行，不能指定。
