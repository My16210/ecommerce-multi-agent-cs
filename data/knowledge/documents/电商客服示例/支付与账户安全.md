# 支付与账户安全

## 一、支持的支付方式

| 方式 | 限额 | 说明 |
| --- | --- | --- |
| 账户余额 | 无单笔上限 | 退款实时到账 |
| 借记卡快捷支付 | 单笔 5 万 | 需绑定实名一致的银行卡 |
| 信用卡 | 单笔 5 万 | 部分银行限额更低，以银行为准 |
| 花呗 | 单笔 5 万 | 需年满 18 岁且通过授信 |
| 分期 | 单笔 3 万 | 期数 3/6/12/24 期，手续费率不同 |
| 数字人民币 | 单笔 1 万 | 需开通对应钱包 |
| 货到付款 | 单笔 2 万 | 部分商品和偏远地区不支持 |

支付限额由**银行侧**和平台侧共同决定，取两者中的较小值。
超过限额的订单可拆分为多笔支付，或改用其他方式。

## 二、支付失败怎么排查

按以下顺序排查，90% 的支付失败在这里就能解决：

1. **卡内余额/额度不足**——最常见。检查可用额度而非账户余额。
2. **单笔或单日限额**——在银行 App 里调高限额，或联系银行客服。
3. **卡片状态异常**——挂失、冻结、未激活的卡片无法支付。
4. **实名信息不一致**——平台实名与银行卡实名必须完全一致。
5. **风控拦截**——异地登录、短时间多次支付失败会触发风控，
   等待 30 分钟后重试，或通过短信验证解除。
6. **网络超时**——支付请求已发出但未收到回应时，**不要重复点击支付**，
   先到订单列表确认是否已支付成功，避免重复扣款。

## 三、重复扣款与退款

发生重复扣款时，多扣的资金会在 **1-7 个工作日**内自动退回，无需申请。
超过 7 个工作日未退回的，联系客服并提供两笔扣款的流水号。

**不要自行联系银行发起"争议交易"**——那会冻结该笔交易，
反而让平台的自动退款流程无法执行，处理时间从几天变成几十天。

## 四、账户安全

### 密码与验证

- 登录密码、支付密码、指纹/面容识别是三层独立的验证，**不要设成同一个**；
- 支付密码连续输错 5 次会锁定 2 小时；
- 更换手机号、更换绑定银行卡需通过原手机号 + 短信双重验证；
- 原手机号已停用的，需走人工申诉，需提供身份证、近期订单信息。

### 盗刷的处理

发现账户被盗刷，按以下顺序处理：

1. **立即冻结账户**：在"设置-安全中心-紧急冻结"一键冻结，或拨打客服电话。
2. **修改密码**：解冻后立即修改登录密码和支付密码。
3. **申请理赔**：账户安全险覆盖范围内的盗刷可申请赔付，
   需提供报案回执（金额 5,000 元以上需先报警）。
4. **保留证据**：订单记录、登录设备记录、与客服的沟通记录。

**账户安全险的除外责任**：主动泄露密码、出借账户、使用非官方客户端、
未开启任何二次验证导致的盗刷，不在赔付范围内。

### 登录设备管理

可在"设置-登录设备"中查看所有已登录设备，支持单个或全部下线。
发现陌生设备应立即下线并修改密码。

## 五、账户信息变更

| 变更项 | 生效时间 | 限制 |
| --- | --- | --- |
| 收货地址 | 立即 | 无 |
| 绑定手机号 | 立即（需双重验证） | 90 日内最多变更 2 次 |
| 绑定银行卡 | 立即 | 需实名一致 |
| 注销账户 | 15 日冷静期后 | 有未完成订单、余额、积分时不可注销 |

注销账户的冷静期内登录任意一次即视为撤销注销申请。
注销后订单记录保留 3 年（法定要求），但账号不可恢复。

## 六、企业账户

企业账户需提交营业执照、法人身份证、对公账户信息，审核 1-3 个工作日。
企业账户的支付走对公转账或企业网银，不支持个人支付方式。
企业账户不参与个人会员积分体系，但享有独立的账期和开票权益。
